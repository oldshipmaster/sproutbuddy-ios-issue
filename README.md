## 中文

### 概述

萌芽伙伴是一款单机使用的任务积分、奖励兑换和宠物陪伴应用。应用不需要账号，不连接服务器，不上传用户数据，不使用广告 SDK，不使用分析 SDK，也不进行用户追踪。

### 我们收集哪些数据

我们不会从本应用收集用户数据。

### 本地保存的数据

为了提供应用功能，以下数据会保存在用户设备本地：

- 任务配置
- 积分记录
- 奖励兑换配置
- 兑换历史
- 宠物状态与成长记录
- 应用语言等本地偏好设置
- 家长密码哈希

这些数据仅保存在设备本地，不会上传给开发者或第三方。

### 权限使用

应用可能使用 Face ID 或 Touch ID 进行家长验证，用于保护赚积分、兑换、设置和重置数据等受限功能。

应用不使用网络、定位、相机、相册、麦克风、通讯录、日历或追踪权限。

### 数据删除

用户可以在应用内使用重置功能删除本地进度数据。卸载应用也会移除应用沙盒内的本地数据。

### 儿童隐私

本应用面向家庭场景，数据保存在设备本地。我们不会收集、上传或出售儿童个人信息。

### 联系我们

如有任何隐私相关问题，请联系：oldshipmaster@gmail.com

### 政策更新

如果本隐私政策发生变化，我们会在新版本或本页面中更新相关说明。

## English

### Overview

SproutBuddy is an offline task, points, rewards, and pet companion app. The app does not require an account, does not connect to a server, does not upload user data, does not use advertising SDKs, does not use analytics SDKs, and does not track users.

### Data We Collect

We do not collect data from this app.

### Data Stored Locally

To provide app functionality, the following data may be stored locally on the user's device:

- Task configuration
- Points records
- Reward configuration
- Redemption history
- Pet status and growth records
- Local preferences such as app language
- Parent password hash

This data stays on the device and is not uploaded to the developer or any third party.

### Permissions

The app may use Face ID or Touch ID for parent verification, such as protecting earning, redemption, settings, and data reset features.

The app does not use network, location, camera, photo library, microphone, contacts, calendar, or tracking permissions.

### Data Deletion

Users can delete local progress data using the reset feature inside the app. Uninstalling the app also removes local data stored in the app sandbox.

### Children's Privacy

This app is designed for family use. Data stays on the device. We do not collect, upload, sell, or share children's personal information.

### Contact

For any privacy-related questions, please contact: oldshipmaster@gmail.com

### Changes to This Policy

If this privacy policy changes, we will update the relevant information in a new app version or on this page.
